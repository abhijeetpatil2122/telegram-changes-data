# Telegram Changes Data

Generated snapshots from the Telegram Changes Checker.

## Data layout

- `production/` — production web resources.
- `production/config/` — sanitized Telegram `help.*` method snapshots.
- `test/` — test resources, grouped by `variant-b`, `variant-i`, `variant-l`, `variant-a`, and `variant-y`.
- `test/config/` — sanitized Telegram `help.*` method snapshots.
- `langpacks/` — Telegram language-pack snapshots.

This repository is maintained automatically by the checker workflow.
